# Support

- Documentation: start with [README.md](README.md) and [docs/guides/troubleshooting.md](docs/guides/troubleshooting.md).
- Bug reports: use the bug report issue template; include `ackit-speckit doctor --json`
  and `ackit-speckit explain --json` output (redacted by construction).
- Feature requests: use the feature request template.
- Security issues: see [SECURITY.md](SECURITY.md) — do not file public issues.
- Upstream issues (ACKit / Spec Kit themselves) belong in their repositories:
  <https://github.com/Cynrath/agent-context-kit>,
  <https://github.com/github/spec-kit>.
