# ACKit Spec Kit Bridge documentation

ACKit Spec Kit Bridge is a community integration between GitHub Spec Kit and ACKit. Spec Kit remains the source of intent, plans and feature specifications. ACKit owns task tracking and evidence-backed verification. The bridge synchronizes them without modifying either upstream product.

## Install

Requires Node.js 22 or newer. GitHub Spec Kit is a separate dependency.

```powershell
npm install --global @cynrath/agent-context-kit @cynrath/ackit-spec-kit-bridge
ackit-speckit version
```

## Inspect verification state

```powershell
ackit-speckit status --json
ackit-speckit verify --profile standard
ackit-speckit gate
```
