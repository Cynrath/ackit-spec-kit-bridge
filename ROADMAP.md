# Roadmap

No dates are promised. Scope is deliberately conservative for v0.1.0.

## v0.2.x

- Richer Spec Kit artifact support (contracts, research, checklists, assessments).
- Additional hook coverage as upstream stabilizes (including `converge` if it
  gains an official hook).
- Improved multi-feature handling beyond active-feature mode.
- GitHub PR checks/status integration.
- Package/catalog distribution improvements (extension catalog inclusion).

## v0.3.x

- Broader provider/integration validation.
- Formal bundle/catalog publishing.
- Deeper ACKit verifier adapters (instruction graph digests, diagnostics
  bundles, SARIF) where stable contracts exist.

## Later / research

- Generic execution-session adapters.
- Browser/runtime evidence adapters.
- Upstream Spec Kit community catalog inclusion if accepted.
- Upstream ACKit plugin API only if real demand proves it useful.
